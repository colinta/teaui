A terminal UI framework for building beautiful fullscreen TUI applications.

## What is TeaUI?

TeaUI lets you build fullscreen terminal applications using **React JSX** or an **Object-Oriented
API**. It handles rendering, input, mouse events, focus management, and layout — so you can focus on
your application logic.

## Quick Start

```bash
pnpm install @teaui/cli
teaui create my-app --framework react
```

Edit `index.tsx`:

```tsx
import React from 'react'
import {interceptConsoleLog} from '@teaui/core'
import {Box, Button, Stack, Text, run} from '@teaui/react'

// Redirect console.info away from the TUI — logs flush on exit
interceptConsoleLog()

function App() {
  return (
    <Box border="single">
      <Stack.down>
        <Text>Hello, TeaUI!</Text>
        <Button>[ OK ]</Button>
      </Stack.down>
    </Box>
  )
}

run(<App />)
```

```bash
npx tsx index.tsx
```
