# Palettes & Styling

TeaUI uses a `Style` object for colors and text decoration, plus component-specific props for borders and layout. All views also accept a `purpose` prop, which selects a `Palette` with semantic colors for surfaces, text, interaction states, selections, and overlays. If `purpose` isn't defined, the palette is inherited from the parent. There are predefined palettes:

- `Palette.plain` — default, muted colors
- `Palette.primary` aka `Palette.blue` e.g. '#3B5EA7'
- `Palette.secondary` aka `Palette.orange` e.g. '#D0851C'
- `Palette.proceed` aka `Palette.green` e.g. '#4A7A5B'
- `Palette.cancel` aka `Palette.red` e.g. '#A04A4C'
- `Palette.selected` optional text styling

## Semantic colors

| Role                   | Property                                                         |
| ---------------------- | ---------------------------------------------------------------- |
| Resting flat control   | `flatBackgroundColor`                                            |
| Resting raised control | `raisedBackgroundColor`                                          |
| Pointer hover          | `hoverBackgroundColor`                                           |
| Keyboard focus         | `focusBackgroundColor`                                           |
| Pointer/key press      | `pressedBackgroundColor`                                         |
| Primary text           | `textColor`                                                      |
| Secondary text         | `mutedTextColor`                                                 |
| Placeholder text       | `placeholderTextColor`                                           |
| Decorative accent text | `accentTextColor`                                                |
| Active selection       | `selectionTextColor`, `selectionBackgroundColor`                 |
| Inactive selection     | `inactiveSelectionTextColor`, `inactiveSelectionBackgroundColor` |
| Modal scrim            | `scrimTextColor`, `scrimBackgroundColor`                         |
| Checked rows           | `checkedBackgroundColor`, `checkedSelectionBackgroundColor`      |

Use `variant: 'flat'` (the default) for controls that blend into their parent, such as `Input` and `CollapsibleText`, and `variant: 'raised'` for controls that stand apart, such as buttons and dropdowns.

Interaction-state precedence is pressed, focus, hover, then rest:

```ts
palette.ui() // flat control at rest
palette.ui({isHover: true})
palette.ui({hasFocus: true})
palette.ui({isPressed: true})
palette.ui({isPlaceholder: true})
palette.ui({variant: 'raised'}) // button or dropdown at rest
```

Use `palette.text()` for passive text surfaces and choose a semantic tone rather than an interaction state:

```ts
palette.text()
palette.text({tone: 'muted'})
palette.text({tone: 'placeholder'})
palette.text({tone: 'accent'})
palette.text({isSelected: true, hasFocus: true})
```

Focus and hover are deliberately separate: hover backgrounds are lighter, while focus backgrounds are darker. Components should pass `hasFocus` to `ui()` rather than treating focus as hover.

## Style Object

```ts
import {Style} from '@teaui/core'

new Style({
  foreground: 'cyan',
  background: 'black',
  bold: true,
  underline: true,
})
```

### Style Properties

| Property     | Type      | Description                                |
| ------------ | --------- | ------------------------------------------ |
| `foreground` | `Color`   | Text color                                 |
| `background` | `Color`   | Background color                           |
| `bold`       | `boolean` | Bold text                                  |
| `dim`        | `boolean` | Dimmed text (mutually exclusive with bold) |
| `italic`     | `boolean` | Italic text                                |
| `underline`  | `boolean` | Underlined text                            |
| `inverse`    | `boolean` | Swap foreground/background                 |
| `strikeout`  | `boolean` | Strikethrough text                         |

## Colors

TeaUI supports multiple color formats:

### Named Colors (16)

`'black'`, `'red'`, `'green'`, `'yellow'`, `'blue'`, `'magenta'`, `'cyan'`, `'white'`, `'gray'`, `'grey'`

Bright variants: `'brightRed'`, `'brightGreen'`, `'brightYellow'`, `'brightBlue'`, `'brightMagenta'`, `'brightCyan'`, `'brightWhite'`

### 256-Color Palette

Use a number `0–255` for the extended terminal color palette:

```ts
new Style({foreground: 196}) // bright red
new Style({background: 236}) // dark gray
```

### RGB Colors

Use an `[r, g, b]` tuple or `#rrggbb` hex code for 24-bit true color:

```ts
new Style({foreground: [255, 128, 0]}) // orange
new Style({background: '#303030'}) // dark background
```

## Borders

Box-drawing border styles:

| Style       | Characters |
| ----------- | ---------- |
| `'single'`  | ┌─┐│└─┘    |
| `'bold'`    | ┏━┓┃┗━┛    |
| `'double'`  | ╔═╗║╚═╝    |
| `'rounded'` | ╭─╮│╰─╯    |
| `'dotted'`  | ┌┈┐┊└┈┘    |

Custom borders via `BorderChars` tuple:

```ts
<Box border={['─', '│', '┌', '┐', '└', '┘']} />
```

## Using Styles in React

Apply styles/purpose via the `style/purpose` prop on `Text`:

```tsx
import React from 'react'
import {Palette, Style} from '@teaui/core'
import {Text, run} from '@teaui/react'

const highlight = new Style({foreground: 'yellow', bold: true})
const purpose = Palette.primary

function App() {
  return (
    <Text style={highlight} purpose={purpose}>
      Important!
    </Text>
  )
}

run(<App />)
```
