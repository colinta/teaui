# Spinner

An animated loading spinner with dots, bouncing, looping, and a Knight Rider–style KITT scanner. Animates when `isAnimating` is true.

<Example name="spinner" title="Spinner" />

## Props

| Prop          | Type                                     | Default  | Description                 |
| ------------- | ---------------------------------------- | -------- | --------------------------- |
| `style`       | `'dots' \| 'bounce' \| 'loop' \| 'kitt'` | `'dots'` | Animation style             |
| `isAnimating` | `boolean`                                | `true`   | Start or stop the animation |

The `dots` spinner is 1×1 cell, `loop` is 5×1, `bounce` is 5×2, and `kitt` is 7×1. Setting `isAnimating` to `false` keeps the current frame visible.

<details>
<summary>Core API</summary>

```js
import {Spinner} from '@teaui/core'

new Spinner({style: 'kitt', isAnimating: true})
```

</details>
