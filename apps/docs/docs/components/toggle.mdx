# Toggle

An iOS-style boolean switch. The slider animates between the left and right positions when toggled.

<Example name="toggle" title="Toggle" />

## Props

| Prop        | Type                       | Default | Description                                  |
| ----------- | -------------------------- | ------- | -------------------------------------------- |
| `value`     | `boolean`                  | `false` | Toggle state                                 |
| `onChange`  | `(value: boolean) => void` | —       | Called when toggled                          |
| `isEnabled` | `boolean`                  | `true`  | Dimmed and not interactive when `false`      |
| `formName`  | `string`                   | `''`    | The name of this value in its [Form](./form) |

## Sizing

`Toggle` has a natural size of `Size(6, 2)`. It also supports `height={1}` for a compact single-line rendering.
