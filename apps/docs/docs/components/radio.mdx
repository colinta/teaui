# Radio and RadioGroup

`RadioGroup` manages one selected value across its descendant `Radio` options. Each `Radio` supplies an option value, and the nearest ancestor group compares it with the group's value to determine which mark to show (`◯` or `⦿`).

<Example name="radio" title="Radio" />

`RadioGroup` is layout-transparent. Put a [`Stack`](./stack) or another layout container inside it to arrange the options. Radios may be nested at any depth, and a nested group takes ownership of its own descendants.

Activating an unselected radio updates the group's value and calls `RadioGroup.onChange`. Activating the selected radio does nothing, so a group cannot be cleared through its radio options. Use unique option values to ensure exactly one radio appears selected.

## RadioGroup props

| Prop       | Type                   | Default     | Description                          |
| ---------- | ---------------------- | ----------- | ------------------------------------ |
| `value`    | `T \| undefined`       | `undefined` | Currently selected option value      |
| `onChange` | `(value: T) => void`   | —           | Called when a new option is selected |
| `children` | `ReactNode` / `View[]` | —           | Content containing the radio options |

## Radio props

| Prop     | Type     | Default | Description                              |
| -------- | -------- | ------- | ---------------------------------------- |
| `value`  | `T`      | —       | Option value compared with the group     |
| `title`  | `string` | —       | Label text                               |
| `hotKey` | `HotKey` | —       | Keyboard shortcut that selects the radio |

`onChange` belongs to `RadioGroup`, not `Radio`. A radio outside a group does not throw an error, but it has no group value to update and cannot report selection changes. Using a standalone radio is unsupported and its behavior should not be relied upon.

## Core API

```ts
import {Radio, RadioGroup, Stack} from '@teaui/core'

const group = new RadioGroup({value: 'one'})
group.add(
  Stack.down([
    new Radio({value: 'one', title: '1'}),
    new Radio({value: 'two', title: '2'}),
  ]),
)
```
