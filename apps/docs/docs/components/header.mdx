# Header

Large text header with underline decoration. React exports the configurable `Header` component and the `H1` through `H6` presets.

<Example name="header" title="Header" />

## Props

| Prop       | Type                                       | Default    | Description          |
| ---------- | ------------------------------------------ | ---------- | -------------------- |
| `text`     | `string`                                   | —          | Header text          |
| `children` | `string`                                   | —          | Header text in React |
| `border`   | `'none' \| 'single' \| 'bold' \| 'double'` | `'single'` | Underline style      |
| `font`     | `FontFamily`                               | —          | Text font            |
| `bold`     | `boolean`                                  | —          | Bold text            |
| `dim`      | `boolean`                                  | —          | Dimmed text          |

React shorthand: `<H1>` = `bold + border="double"`, `<H2>` = `bold + border="bold"`, `<H3>` = `bold + border="single"`, `<H4>` = `border="single"`, `<H5>` = `dim + border="single"`, `<H6>` = `dim + border="none"`.
