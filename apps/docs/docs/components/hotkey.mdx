# HotKey

Registers a global keyboard shortcut. `HotKey` is non-visual; render any related label or instructions as sibling content.

<Example name="hotkey" title="HotKey" />

## Props

| Prop      | Type                        | Default | Description                        |
| --------- | --------------------------- | ------- | ---------------------------------- |
| `hotKey`  | `HotKey`                    | —       | Key combination to listen for      |
| `label`   | `string`                    | —       | Label shown by `AutoLegend`        |
| `onPress` | `(event: KeyEvent) => void` | —       | Called when the hot key is pressed |

### HotKey type

```ts
type HotKey = {
  char: string // The key character
  ctrl?: boolean // Require Ctrl modifier
  gui?: boolean // Require Gui modifier
  shift?: boolean // Require Shift modifier
}
```

<details>
<summary>Core API</summary>

```js
import {HotKey, Stack, Text} from '@teaui/core'

Stack.down([
  new HotKey({
    hotKey: {char: 'q', ctrl: true},
    label: 'Quit',
    onPress() {
      // Handle Ctrl+Q
    },
  }),
  new Text({text: 'Ctrl+Q'}),
])
```
