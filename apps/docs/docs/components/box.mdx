# Box

A container with optional border and padding.

<Example name="box" title="Box" />

## Props

| Prop        | Type                                                                                                                                                                               | Default    | Description                                  |
| ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------- | -------------------------------------------- |
| `border`    | `'single' \| 'bold' \| 'double' \| 'rounded' \| 'dotted' \| 'dashed' \| 'ascii' \| 'mixed' \| 'mixed-alt' \| 'shade' \| 'block' \| 'shadow' \| 'corners' \| 'none' \| BorderChars` | `'single'` | Border style (or custom `BorderChars` tuple) |
| `highlight` | `boolean`                                                                                                                                                                          | `false`    | Use highlight style for the border           |
| `padding`   | `number \| {top, bottom, left, right}`                                                                                                                                             | `0`        | Inner padding (inherited from View)          |
| `children`  | `ReactNode`                                                                                                                                                                        | —          | Child views                                  |

The exported `BORDERS` array contains all preset border names. See [Borders](/docs/themes#borders) for previews and custom `BorderChars` tuple formats.
