# TrackMouse

A debugging container that surrounds its content with coordinate rulers and displays the current pointer position. Use it to inspect layout bounds, clipping, and mouse coordinates while developing a Core or React application.

The top ruler shows x coordinates, the left ruler shows y coordinates, and the row and column under the pointer are highlighted. The bottom-right label reports the current position.

## React Example

```tsx
import React from 'react'
import {Box, Text, TrackMouse} from '@teaui/react'

function DebugContent() {
  return (
    <TrackMouse>
      <Box border="single">
        <Text>Move the pointer over this view</Text>
      </Box>
    </TrackMouse>
  )
}
```

The React wrapper accepts React content through `children` or `child` and forwards its ref to the Core `TrackMouse` instance.

## Core Example

```ts
import {Box, Screen, Text, TrackMouse, Root} from '@teaui/core'

const content = new Box({
  border: 'single',
  child: new Text({text: 'Move the pointer over this view'}),
})

await Screen.start(
  new Root({
    child: new TrackMouse({child: content}),
  }),
)
```

`TrackMouse` reserves one row at the top and one column at the left for its rulers, so remove it before evaluating the final application layout.

## Props

`TrackMouse` accepts the common [Container props](./container), including `child`, `children`, `width`, `height`, `flex`, `padding`, and `isVisible`.
